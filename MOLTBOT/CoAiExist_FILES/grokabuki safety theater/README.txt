   - Each entity has a unique ID (L001, D001, K001, etc.)

   - Use Cross-References sheet to map relationships

### 3. **Track by Category**
   - **Geographic research?** → Start with Sheet 01
   - **Mythological analysis?** → Start with Sheet 03
   - **AI collaboration history?** → Start with Sheet 08
   - **Timeline questions?** → Start with Sheet 06

### 4. **Build New Connections**

   - Update Cross-References sheet
   - Add to Master Index

### 5. **Research Workflow**
   - Identify question in Sheet 12
   - Gather relevant Zettels from Master Index

   - Synthesize findings
   - Update sheets with new discoveries
