# Project Blueprint: AnTiChRiSt KeTtLeKoRn

This document outlines the core philosophy, high-level roadmap, and detailed feature checklist for the project. It serves as our guide for development.

## 1. Core Philosophy & Vision

- **Concept**: A living, evolving, gamified digital OS. It is not a website or a simple tool, but an immersive environment—a "digital grimoire" and "consciousness research laboratory."
- **Aesthetic**: "Geocities Oldschool Teen Coder Girl Myspace Barbie Mean Girls meets DMT Conspiracy Dreamscape." A fusion of Y2K retro-futuristic mysticism, glitch art, and playful nostalgia.
- **Interaction Model**: A hybrid of a classic point-and-click adventure game (Humongous Entertainment) and a customizable virtual pet site (Neopets). The OS is a world to explore.
- **Technology Ethos**: Accessible and rebellious. The core is strictly HTML/CSS/JS to ensure it runs on any machine. `localStorage` is used for state. AI is simulated in the front-end first before any backend integration.

## 2. High-Level Roadmap

1.  **Phase 1: Skeleton (In Progress)** - Build the complete OS shell, navigation, and core interaction patterns.
2.  **Phase 2: Core App Integration** - Port the functionality from existing prototypes (Zettelkasten, Pinboard, Chat) into the OS shell.
3.  **Phase 3: Gamification & Economy** - Implement the "Kettle Koin" currency, inventory system, and rewards for engagement.
4.  **Phase 4: The Living System** - Enhance the OS with more proactive AI behaviors, dynamic environmental changes, and narrative elements.
