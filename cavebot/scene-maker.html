How to use
  1. Copy this file to index.html and open it in any browser.
  2. Assets Panel: drag Cavebot assets onto the stage.
  3. Inspector: click an object to edit Name, X/Y, Cursor, and Action.
  4. Preview Mode: toggle Preview interactions to test clicks/cursors.
  5. Export the scene JSON to load into your game engine.
