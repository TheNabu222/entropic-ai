NABU OS v5.0 - MASTER ARCHIVE SYSTEM
======================================

This is a self-contained, single-file HTML application designed for Neocities.

FILES:
- nabu_complete.html: The main application file.

INSTRUCTIONS:
1. Upload `nabu_complete.html` to your Neocities root directory.
2. Rename it to `index.html` if you want it to be your homepage.
3. Open the site in your browser.

FEATURES:
- **Master Archive**: Browse your Zettelkasten notes in Card or Tree view.
- **Scribe's Chisel**: Paste raw text to automatically index and categorize notes using advanced keyword heuristics.
- **Ley Line Mapper**: Visualize connections between notes with a D3 force-directed graph.
- **Persistence**: All data is saved to your browser's LocalStorage. It persists across reloads.
- **Backup/Restore**: Export your database to JSON and restore it on any device.
- **Safety Analysis**: Built-in documentation on the Quintuple Bind and AI Safety.

USAGE:
- **Ingestion**: Open "Scribe's Chisel", paste your raw text notes (e.g., from your .txt files), and click "DECODE & INDEX".
- **Organization**: The system automatically assigns categories (Location, Deity, Concept, etc.) and Trunks based on keywords.
- **Editing**: Click on any note in the Archive or Graph to view details. You can "Smash Tablet" (delete) from the detail view.
- **Reset**: Use the "NUKE ARCHIVE" button in the Archive window to clear all data and start fresh.

SYSTEM REQUIREMENTS:
- A modern web browser (Chrome, Firefox, Edge, Safari).
- No server required.
